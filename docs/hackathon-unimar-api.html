01 O que são esses dados

A Sisfrete é uma plataforma de cotação de frete. Quando uma loja de e-commerce precisa enviar um produto, ela consulta a Sisfrete informando origem, destino, peso e dimensões. A plataforma consulta as tabelas de várias transportadoras e devolve as opções disponíveis, com preço e prazo.

Cada documento no índice quotations-* é uma dessas consultas, contendo o contexto do envio (CEP de destino, cidade, peso, cubagem, canal de venda) e um array com as cotações devolvidas por cada transportadora — frete, pedágio, GRIS, prazo e total.

Isso abre perguntas como: qual transportadora é mais barata por região? Como o preço varia com peso e distância? Existe padrão entre canal de venda e custo? Qual o prazo médio por rota?

03 O que seu acesso permite

É uma credencial somente leitura, limitada aos índices do desafio.

Permitido
  • GET / — teste de conexão
  • GET /_cat/indices/quotations-*?format=json
  • GET|POST /<indice>/_search — buscar e agregar
  • GET /<indice>/_count
  • GET /<indice>/_mapping
  • GET /<indice>/_field_caps?fields=*
  • POST /_msearch
  • scroll e search_after
Bloqueado — retorna 403
  • Qualquer escrita: criar, alterar ou apagar
  • Índices fora do escopo, inclusive os de sistema
  • GET /_cat/indices sem padrão
  • APIs de segurança e de usuários
  • A interface web do OpenSearch Dashboards
Por que tão restrito

O mesmo cluster atende clientes reais em produção durante o evento. As permissões foram calibradas endpoint a endpoint para liberar análise sem abrir risco.

Nomenclatura dos índices

padrão
quotations-<id_cliente>-<AAAA.MM>      // ex.: quotations-1090-2026.09
pedidos-<id_cliente>-<AAAA.MM>         // ex.: pedidos-861-2026.09

Cada loja cliente tem seus próprios índices mensais. quotations-* busca em todas; quotations-*-2026.09 restringe ao mês; quotations-1090-* restringe a um cliente. O período coberto vai de 01/08/2026 até hoje.

Python

python
import requests

BASE = "https://api.opensearch.sisfrete.com.br"
AUTH = ("unimar-grupo-01", "SUA_SENHA")

r = requests.post(
    f"{BASE}/quotations-*-2026.09/_search",
    auth=AUTH,
    json={
        "size": 0,
        "aggs": {
            "faixa_peso": {
                "histogram": {"field": "nf.peso", "interval": 10},
                "aggs": {"custo_medio": {"avg": {"field": "nf.cotacoes.total"}}},
            }
        },
    },
    timeout=120,
)
r.raise_for_status()
for b in r.json()["aggregations"]["faixa_peso"]["buckets"]:
    print(b["key"], b["doc_count"], round(b["custo_medio"]["value"] or 0, 2))

07 Extrair muitos documentos

from/size só alcança os primeiros 10.000 resultados. Para volumes maiores use search_after, mais leve para o cluster que scroll:

json
{
  "size": 1000,
  "sort": [{ "@timestamp": "asc" }, { "_id": "asc" }],
  "query": { "range": { "@timestamp": { "gte": "2026-09-01" } } }
}

Pegue o campo sort do último documento retornado e repita a consulta acrescentando "search_after": [valores do sort]. Continue até vir zero resultados.

Para um recorte de trabalho local, considere puxar um cliente e um mês — quotations-1090-2026.09 — em vez de varrer quotations-*.

08 Armadilhas

nf.cotacoes é array de objeto, não nested

Os valores são achatados pelo motor de busca. Uma consulta como “transportadora 500 e total acima de 200” pode casar um documento onde a transportadora 500 cobrou 150 e outra transportadora cobrou 250 — porque as duas condições foram satisfeitas por elementos diferentes do array. Para correlacionar campos dentro da mesma cotação, extraia os documentos e cruze no seu código.

Muitos campos vêm vazios

Dos 55 campos de uma cotação, tipicamente cerca de 16 estão preenchidos; o resto fica 0, "" ou false. Campos como nf.destinatario e nf.apelido estão vazios em toda a base. Confirme com exists antes de assumir que um campo tem conteúdo.

Datas são UTC

@timestamp está em UTC e o horário de Brasília é UTC−3. Uma cotação das 20h de 31/08 aparece como 2026-09-01T23:00Z. Ajuste com "time_zone": "-03:00" nas agregações de data.

Consultas amplas são lentas

quotations-* toca cerca de 2.680 shards e uma agregação leva de 2 a 6 segundos. Restringir ao mês ou a um cliente reduz muito. Use "size": 0 quando só quiser a agregação — evita transferir documentos à toa.

Os dados mudam durante o evento

Setembro segue recebendo cotações reais, então duas execuções da mesma consulta podem dar números diferentes. Se precisar de números estáveis para apresentar, congele com um filtro range de data fechado.

10 Regras de uso

Este cluster atende clientes reais em produção durante o hackathon.

  • Não rode varreduras contínuas em laço sobre quotations-*
  • Prefira agregações no servidor a baixar tudo e processar localmente
  • Mantenha concorrência baixa — 2 a 3 requisições simultâneas por grupo
  • A credencial é do grupo: não compartilhe fora dele
  • Os dados são comerciais e reais. Não republique, não poste em repositório público e não use fora do hackathon
  • Os acessos são revogados ao fim do evento
Problemas com a credencial

Falar com a organização do evento.
